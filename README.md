# 每公里真实成本计算器

一个基于"资产消耗 + 运营消耗"硬核算法的车辆使用成本计算工具。专注于计算**每开一公里，钱包里实际少了多少钱**。

## 核心算法

### 真实成本公式

```
每公里真实成本 = 资产损耗 + 能源消耗 + 维保系数 + 固定成本分摊
```

### 详细拆解

1. **资产损耗**：基于剩余寿命计算每公里车价折损
2. **能源消耗**：考虑城市/高速比例的油耗成本
3. **维保系数**：动态计算，根据里程、车龄、品牌调整
4. **固定成本**：保险、年检、税费、停车费等分摊

## 功能特点

- ✅ **硬核算法**：去繁就简，专注真实使用成本
- ✅ **动态维保系数**：根据里程、车龄、品牌智能调整
- ✅ **品牌差异化**：支持日系、德系、美系、韩系、豪车等不同品牌
- ✅ **车况考虑**：根据车况调整最大寿命
- ✅ **残值模式**：支持"开到报废"和"中途卖出"两种模式
- ✅ **响应式设计**：完美支持PC和移动端
- ✅ **简洁界面**：现代化UI设计，操作简单直观

## 使用方法

1. 直接在浏览器中打开 `index.html`
2. 填写车辆信息（必填项已标注）
3. 点击"计算真实成本"按钮
4. 查看详细的成本明细和车辆信息

## 算法说明

### 品牌可靠性系数

- 日系：1.0（基准值）
- 韩系：0.95
- 德系：0.90
- 美系：0.85
- 豪车：0.85

### 车况系数

- 精品车况：1.0
- 正常使用：0.95
- 一般车况：0.85
- 较差车况：0.70

### 维保系数计算

根据里程分段：
- 0-10万公里：基础系数
- 10-20万公里：+30%
- 20万+公里：+80%

根据车龄：每年增加5%

根据品牌：豪车系数 ×1.5
